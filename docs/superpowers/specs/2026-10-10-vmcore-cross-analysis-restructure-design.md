## 4. 关键论证设计

### 4.1 §4 频率维度推导链

数据（统一口径：在线时长 / 事件数 / 负载 / 频率档）→ 频率依赖现象成立（2.9 GHz 分钟级即崩 → 2.0 GHz 3 小时 5 事件 → 1.45 GHz 小时-天级出错）→ 机制推导：频率升高 → 时钟周期缩短 → 边际路径 setup/hold 裕量耗尽 → 出错率上升；与频率无关的固定粘滞位缺陷对比 → 结论：**时序/电压裕量劣化形态**。混杂因素如实声明：各档负载不同（zstd19/probe+stressng/40 项全核批次）、每档 n=1、"1.45 GHz 可存活"不等于安全档（案①②皆在此档崩溃）。判别途径：后续频率扫描以"用户态 bit 级检出率（xor 分布直方图）"替代"存活/崩溃"作为更灵敏观测量。

### 4.2 §5.4 亚型统一性论证（核心新增）

- 甲=整值陈旧行交付（9-29 x19 外来值 / 9-30+9-17Boot1 SP 陈旧指针 / 10-09 freeptr 8 空格 / 9-29 时钟陈旧值）；乙=单比特位错（bit15×3、bit61、bit2）。
- ① 乙不可归约为甲：9-29 x21 与任何 CPU 的 rq 差 0x24000 间距，非错行可解释。
- ② 甲不可归约为乙：8 空格、外来 ns 值非任何期望值的单比特变体。
- ③ 观测层面双机制并存，候选假设逐一对全部六观测检验：**H1 两独立缺陷**；**H2 单一边际位单元双重表现**（该位处于行选择元数据→甲，处于数据暂存→乙）；**H3 错行取到同行陈旧版本**（1 比特差的"旧值"）。
- bit15 三连发对 H2 的支持强度如实评估：bit61/bit2 为反例压力，且 bit 位置集中在 n=5 样本上统计力有限——结论分级表述。
- 判别途径：后续事件的位位置直方图积累；FA 失效单元检查清单据此细化。

### 4.3 §5.3 热路径基率效应声明

"三案根因事件集中于调度器 tick/中断返回/分配器热路径"逐案映射（① psi_account_irqtime←scheduler_tick；② el0_interrupt/exit_to_user_mode+irqtime/sched_clock 链；③ pcp/slab freelist）后，必须声明：热路径也是任何核上运行最频繁的路径——故障随机激发也会优先在热路径显形，现有数据不能完全分离"负载触发"与"随机激发+热路径主导显形"两种解释；引用崩溃循环报告 §4.4"无需用户负载"作为方向性佐证。

时间对账（**此衔接链为待验证假设，须在 §3.1 对账中用 SEL/黑匣子/操作日志验证 11:17:53 kdump 完成与 11:19 首次复位的确切对应**）：10-09 11:16:03 E3 panic → kdump 37 s 成功（11:17:53）→ 崩溃内核重启 → 11:19 起进入当日异常复位序列（午后段呈 17′12″ 看门狗周期循环，详见崩溃循环报告 §1.1/§6）。两报告互补分工：本文案③证明 11:16 前三小时退化弧（E1/E2/用户态检出/E3），崩溃循环报告证明其后 12 小时传播链（BMC 黑匣子五次 panic + SBSA 看门狗）；其 §6.4"vmcore 缺失"指其后续复位循环中 kdump 未再成功（早期启动 kdump 未就绪 / 23:35 被 SBSA 看门狗中止），与本案 11:16 成功捕获不矛盾——衔接段须把这一点讲清，消除两文表观冲突。
