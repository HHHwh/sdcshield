## 0. 问题一句话

256 腿分诊表把 25 个超时格以 clamp 下限（负载缩小 3~4 个数量级）的有界重跑
计为绿，§7 收口宣布「190/190 全绿、边界格 = 0」——把 spec 定义的「边界格」
（机制性不可达、允许带显式理由）偷换成「找不到有界值的残留」（=0），与
自身 §4「根因（环境/边界类，非代码 bug）」定性矛盾；SDC 语境下检出概率随
激发占空比缩放，clamp 下限绿只证明该配置可执行，不证明设计负载几何通过。

## 2. 根因

**证据矩阵的收口语义与验收判据分离**。spec 验收判据的「全绿」以设计负载
（自适应几何）为默认语义，「边界格」为机制性不可达格的豁免通道；分诊表
在超时格处置中把「clamp 下限首次通过即止」（零上调阶梯）的有界重跑结果
**直接并入全绿计数**，并重定义「边界格 = 找不到有界值的残留」使该计数
自洽——结果是 §4 诚实定性（环境/边界类）与 §7 收口（全绿、边界格=0）
在同一文档内互相矛盾。SDC 语境（CLAUDE.md 使命：以压力激发检出静默数据
腐坏；cases 历史如 CPU179 故障窗口占空比 ~0.06%）下，激发强度缩小
3~4 个数量级直接等比压缩检出概率——clamp 下限绿是**功能正确性 + 最小
激发强度**证据，不是满强度激发证据。根因是**验收语义未在运动 spec 里
对「有界绿」预先定义**（spec 只定义了全绿与边界格两类），处置时 improvised
出第三类却计入第一类口径。
